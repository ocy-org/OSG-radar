# OSG-radar
本项目是opengl OSG实现飞机模型在真实地图上飞行的3D效果的桌面应用。

# 技术特点
- 3D飞机模式加载<br>
- china.geo.json地图数据加载<br>
- 飞机根据指定坐标飞行，并显示飞机飞行的航线、航迹<br>
- 态势区域感知：飞过哪个区域，哪个区域高亮，以及显示预警信息<br>
